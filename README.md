# DevOps Platform

A hands-on DevOps portfolio project focused on building,
deploying, and operating a web application using real-world
DevOps practices.

## Project Overview

DevOps Platform uses a Travel Journal web application as
a practical workload to demonstrate the software delivery
lifecycle, infrastructure automation, containerization,
CI/CD, cloud deployment, monitoring, and security.

## Objectives

- Build and maintain a version-controlled application.
- Containerize the application with Docker.
- Implement automated CI/CD pipelines.
- Provision infrastructure using Terraform.
- Explore cloud deployment with AWS.
- Learn Kubernetes deployment and operations.
- Implement monitoring, logging, and security practices.
- Document setup, architecture, and operational procedures.

## Application

**Travel Journal** is the reference web application used
to apply and validate DevOps practices.

## Planned Technologies

- Git and GitHub
- Linux and Bash
- Node.js
- Docker and Docker Compose
- GitHub Actions
- Terraform
- AWS
- Kubernetes
- Monitoring and logging
